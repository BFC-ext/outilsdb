Politique de confidentialité — Outils DB

En vigueur le 7 novembre 2026 · version 1.0.0 de l'extension

Outils DB est une extension de navigateur publiée par [ÉDITEUR] pour l'usage interne du cabinet. Elle réunit des outils de travail sur la base Odoo que l'utilisateur a ouverte dans son navigateur, avec la session qu'il y a déjà ouverte, et, pour l'outil « Vers Silverfin », sur le dossier Silverfin qu'il a ouvert.

Les données traitées

Selon l'outil employé, l'extension lit dans la base Odoo ouverte : écritures et états comptables, sociétés, partenaires, journaux, immobilisations, véhicules, langues installées, et les noms et identifiants de connexion des utilisateurs de cette base. Elle lit aussi les pages Odoo et Silverfin ouvertes par l'utilisateur.

Ces données ne servent qu'à ce que l'utilisateur demande : afficher une analyse, produire un fichier, télécharger une sauvegarde, recharger des traductions, transférer des données vers Silverfin.

Où vont les données

Les données transitent uniquement entre le navigateur de l'utilisateur, sa base Odoo et son dossier Silverfin. L'extension n'interroge aucun autre serveur. Rien n'est transmis à l'éditeur de l'extension ni à un tiers.

L'extension n'écrit dans Odoo ou dans Silverfin que sur une action explicite de l'utilisateur : bascule de publication automatique des fournisseurs qu'il a cochés, rechargement des traductions qu'il a confirmé, envois vers Silverfin qu'il a autorisés.

Ce qui est conservé

Sur le poste, dans le stockage local du navigateur : les réglages des outils (langue, délais, choix de documents, préférences d'affichage). Les fichiers que l'utilisateur demande de produire — états, archives, sauvegarde, fichiers d'import — sont enregistrés dans le dossier qu'il choisit, sur son poste, et restent sous sa seule garde.

Aucune donnée n'est conservée ailleurs que sur le poste de l'utilisateur.

Ce qui n'est pas fait

  • Aucune donnée n'est vendue, louée ni cédée.
  • Aucune donnée ne sert à un autre usage que la fonction de l'extension.
  • Aucune donnée ne sert à évaluer la solvabilité ni à accorder un crédit.
  • Aucune publicité, aucune mesure d'audience, aucun profilage.
  • Aucun mot de passe ni aucune clé d'API n'est demandé ni conservé : l'extension utilise la session déjà ouverte, avec les droits de l'utilisateur.

Suppression

Désinstaller l'extension supprime l'intégralité des données qu'elle conserve dans le navigateur. Les fichiers enregistrés sur le poste se suppriment comme tout autre fichier.

Privacybeleid — Outils DB

Van kracht op 7 november 2026 · versie 1.0.0 van de extensie

Outils DB is een browserextensie van [ÉDITEUR] voor intern gebruik binnen het kantoor. Ze bundelt werktools voor de Odoo-database die de gebruiker in zijn browser heeft geopend, met de sessie die hij daar al heeft, en, voor de tool „Naar Silverfin”, voor het Silverfin-dossier dat hij heeft geopend.

Verwerkte gegevens

Naargelang de gebruikte tool leest de extensie in de geopende Odoo-database: boekingen en boekhoudstaten, bedrijven, partners, dagboeken, vaste activa, voertuigen, geïnstalleerde talen, en de namen en aanmeldingsnamen van de gebruikers van die database. Ze leest ook de Odoo- en Silverfin-pagina's die de gebruiker heeft geopend.

Deze gegevens dienen uitsluitend voor wat de gebruiker vraagt: een analyse tonen, een bestand maken, een back-up downloaden, vertalingen herladen, gegevens naar Silverfin overbrengen.

Waar de gegevens naartoe gaan

De gegevens gaan uitsluitend tussen de browser van de gebruiker, zijn Odoo-database en zijn Silverfin-dossier. De extensie raadpleegt geen enkele andere server. Er wordt niets doorgegeven aan de uitgever van de extensie of aan derden.

De extensie schrijft in Odoo of Silverfin alleen na een uitdrukkelijke handeling van de gebruiker: het automatisch boeken inschakelen voor de leveranciers die hij heeft aangevinkt, het herladen van vertalingen dat hij heeft bevestigd, overdrachten naar Silverfin die hij heeft toegestaan.

Wat wordt bewaard

Op het toestel, in de lokale opslag van de browser: de instellingen van de tools (taal, termijnen, keuze van documenten, weergavevoorkeuren). De bestanden die de gebruiker laat maken — staten, archieven, back-up, importbestanden — worden opgeslagen in de map die hij kiest, op zijn toestel, onder zijn eigen beheer.

Er worden nergens anders gegevens bewaard dan op het toestel van de gebruiker.

Wat niet gebeurt

  • Er worden geen gegevens verkocht, verhuurd of overgedragen.
  • Gegevens dienen voor geen ander doel dan de functie van de extensie.
  • Gegevens dienen niet om kredietwaardigheid te beoordelen of krediet toe te kennen.
  • Geen reclame, geen bezoekersmeting, geen profilering.
  • Er wordt geen wachtwoord of API-sleutel gevraagd of bewaard: de extensie gebruikt de reeds geopende sessie, met de rechten van de gebruiker.

Verwijdering

Het verwijderen van de extensie wist alle gegevens die ze in de browser bewaart. Bestanden op het toestel worden verwijderd zoals elk ander bestand.

Privacy policy — Outils DB

Effective 7 November 2026 · extension version 1.0.0

Outils DB is a browser extension published by [ÉDITEUR] for the firm's internal use. It brings together work tools for the Odoo database the user has opened in their browser, using the session already open there, and, for the “To Silverfin” tool, for the Silverfin file the user has opened.

Data processed

Depending on the tool used, the extension reads from the open Odoo database: journal entries and accounting reports, companies, partners, journals, fixed assets, vehicles, installed languages, and the names and login names of that database's users. It also reads the Odoo and Silverfin pages opened by the user.

This data is used only for what the user asks for: displaying an analysis, producing a file, downloading a backup, reloading translations, transferring data to Silverfin.

Where the data goes

Data travels only between the user's browser, their Odoo database and their Silverfin file. The extension contacts no other server. Nothing is sent to the extension's publisher or to any third party.

The extension writes to Odoo or Silverfin only on an explicit action by the user: enabling automatic posting for the vendors they ticked, reloading translations they confirmed, transfers to Silverfin they authorised.

What is kept

On the device, in the browser's local storage: the tools' settings (language, grace periods, document choices, display preferences). Files the user asks to produce — reports, archives, backup, import files — are saved in the folder they choose, on their device, in their sole keeping.

No data is kept anywhere other than on the user's device.

What is not done

  • No data is sold, rented or transferred.
  • No data is used for any purpose other than the extension's function.
  • No data is used to assess creditworthiness or for lending.
  • No advertising, no analytics, no profiling.
  • No password or API key is asked for or stored: the extension uses the session already open, with the user's rights.

Deletion

Uninstalling the extension deletes all data it keeps in the browser. Files saved on the device are deleted like any other file.
