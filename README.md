# Politiques de confidentialité des extensions du cabinet

Pages publiques exigées par le Chrome Web Store. Une page par extension, dans
son propre dossier ; son adresse est celle inscrite sur la fiche du store.

| Extension | Page |
|---|---|
| Outils DB (Odoo-16) | [outils-db/](outils-db/) |

Ne rien déposer d'autre dans ce dépôt : tout ce qu'il contient est public.
Ne pas renommer un dossier : l'adresse est inscrite au store.
